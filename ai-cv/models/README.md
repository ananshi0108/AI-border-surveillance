# Models directory (weights are gitignored — download/train, don't commit)

Run `python scripts/download_models.py` to fetch:
- `yolov8n.pt` — base YOLOv8 detector (person/vehicle classes already in COCO)
- `face_detection_yunet_2023mar.onnx` — YuNet face detector

Optional, project-specific (not auto-downloaded):
- `plate_yolov8n.pt` — fine-tune on a labeled license-plate dataset for accurate ANPR
  (without this, `src/anpr/plate_detector.py` falls back to a classical contour method)
- `zero_dce.pth` — train with `src.enhancement.zero_dce.train_zero_dce()` on
  border-camera night footage, or download the official pretrained snapshot
  from https://github.com/Li-Chongyi/Zero-DCE
- `yolov8n.onnx` / `yolov8n.engine` — generated by `src/export/export_onnx.py`
  and `src/export/quantize.py` for edge deployment
